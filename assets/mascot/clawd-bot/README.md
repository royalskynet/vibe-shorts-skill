# Clawd Bot（智能機械蟹）— 常用角色設計規範與動畫參數設定書

`vibe-shorts` 常駐吉祥物／助教角色。設計核心為**「一體成形、100% 左右對稱、極簡幾何線條」**，兼具 Claude 品牌識別（陶土橘＋星芒訊號天線）與極客終端機靈魂（LED 智慧面罩＋懸浮 C 型機械螯），可透過純程式碼（SVG / Remotion / Motion Canvas / Canvas）零成本驅動 60fps 動畫。

---

## 4. 動畫狀態機與物理公式（Animation State Machine）

以時間 `t`（秒）驅動，支援即時 `requestAnimationFrame` 或影片逐幀渲染（`t = frame / fps`）：

| 狀態 (`state`) | 速度倍率 (`speedMult`) | 全身呼吸浮動 (`bobY`) | 懸浮雙螯動作 (`claw-l` / `claw-r`) | 天線星芒旋轉 (`crab-spark`) |
|---|---|---|---|---|
| **`idle`（待機呼吸）** | `1.0` | `sin(t * 2.5) * 4.5` | 上下慢速懸浮 `y = 2 ± sin(t * 3) * 4`，微轉 `±sin(t * 2) * 6°` | `t * 90°` |
| **`thinking`（思考／寫Code）** | `2.2` | `sin(t * 5.5) * 4.5` | 內收至 `x = ∓58`，左右交替高速敲擊鍵盤 `y = 2 + sin/cos(t * 24) * 6`，傾角 `±15°` | `t * 198°`（高速旋轉） |
| **`happy`（開心完成）** | `2.8` | `-abs(sin(t * 7)) * 15`（彈跳） | 高舉至 `(∓64, -10)`，歡呼揮動 `±(25 + sin(t * 14) * 18)°` | `t * 252°` |
| **`sleep`（撞錯／休眠）** | `0.5` | `5 + sin(t * 1.4) * 1.8`（下沉） | 收納貼合機身 `(∓54, 10)`，下垂角 `∓12°` | `t * 45°`（慢速） |

### 附加物理效果
- **呼吸微果凍縮放（Squash & Stretch）**：
  - `scaleX = 1 + sin(phase) * 0.03 + pokeEffectX`
  - `scaleY = 1 - sin(phase) * 0.03 - pokeEffectY`
- **視線追蹤（Look-At Clamping）**：
  - 目標方向 `(nx, ny) ∈ [-1, 1]`，以阻尼係數 `0.12` 平滑插值，面罩內五官最大位移 `translate(nx * 7, ny * 4.5)`，不會超出面罩邊界。
