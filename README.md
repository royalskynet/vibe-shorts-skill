# vibe-shorts — a Claude Code skill for fully programmatic short films

繁中在下面 ↓

A handoff-complete skill for a 9:16 short-video pipeline where **every asset is generated by code**: no AI image generation, no video editor, no human voice-over, no third-party TTS API.

- **Graphics** — one `index.html` exposing `render(t)`, screenshotted frame by frame with headless Chromium, then muxed with ffmpeg.
- **Animation** — every moving part is a pure function of `t` (`poseAt(t)`). Required, not stylistic: the renderer runs parallel workers that each cold-start at a different frame, so accumulated state desyncs the seams. A seek-consistency gate compares cold-start frames against continuation frames byte for byte.
- **Audio** — on-device Qwen3-TTS for narration (voice identity is a reference clip, not a vendor voice id), every line re-read until Whisper transcribes it back above a similarity floor, music and SFX synthesised from sine waves in the film's own `mix.py`.
- **Gates** — a zero-token pre-publish checker: cover-frame luminance and OCR, narration-in-master ASR similarity, shot-grid vs. cut boundaries, motion baselines per film format, source attribution for every number on screen, adversarial fact audit, and a self-review score floor.
- **Delivery** — one master out to three platform-specific files, loudness normalised, metadata scrubbed, container flags set for each platform's quirks.

## Install

```bash
git clone https://github.com/royalskynet/vibe-shorts-skill ~/.claude/skills/vibe-shorts
```

Then ask Claude Code to make a film. `SKILL.md` is the router; read `references/` on demand.

# vibe-shorts — 全程式生成短片的 Claude Code 技能包

9:16 短影音流水線的交接級技能包。**畫面、動畫、聲音全部由程式生成**：沒有 AI 生圖、沒有剪輯軟體、沒有真人配音、沒有外部 TTS API。

- **產圖** —— 一支 `index.html` 對外只暴露 `render(t)`，用 headless Chromium 逐幀截圖，再 ffmpeg 合軌。
- **產動畫** —— 每個會動的東西都是 `t` 的純函數（`poseAt(t)`）。這是被逼出來的設計：渲染器開多個 worker 各自從不同幀冷啟動，累積狀態會讓接縫跳動。尋幀一致閘門會把冷啟動的幀與接續的幀逐位元組比對。
- **做聲音** —— 本機 Qwen3-TTS 配音（音色是一段範本音檔，不是供應商的 voice id），每句念完用 Whisper 聽回來比稿，不到門檻就重念；配樂與音效在各片自己的 `mix.py` 用正弦波合成。
- **閘門** —— 發布前的零 token 機械檢查：封面幀亮度與 OCR、旁白是否真的混進成片、鏡頭格線與切點、按片型分流的動態基準、畫面上每個數字的來源、反方稽核、目視自評分數下限。
- **交付** —— 一支成片出三個平台檔，響度統一、元資料清除、容器旗標按各平台的坑設定。
